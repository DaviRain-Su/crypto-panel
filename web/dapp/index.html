Ask the local wallet to sign

This page runs in Crypto Panel's isolated web view. It can ask the wallet to connect and to sign; it never sees a key, and every request opens the shell's own approval window.

1 · Connect

2 · Send NEAR

3 · Add a function-call key

The key is limited to one contract, a method list and an allowance. The approval window shows the limit before the account signs it.

The page is served from . Crypto Panel accepts a DApp origin over HTTPS, or HTTP on localhost, and reads the origin from the web view's own URL — never from this page's request.
